# Built-in icons

- `mono/`: Tabler Icons (outline), MIT, Copyright (c) 2020-2026 Paweł Kuna. See `mono/LICENSE`.
- `color/`: Fluent Emoji (Flat), MIT, Microsoft Corporation. See `color/LICENSE`.

They are embedded in `Gaya.Host`, written to the user's cache on first use and referenced by `Themes/gaya.icons.mono.pss` and `Themes/gaya.icons.color.pss`.
