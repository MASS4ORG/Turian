# Turian Engine

Runtime libraries for scenes, components, assets, input and rendering.

- [Core](Core/): engine runtime and service contracts; no GPU or window dependency.
- [Vulkan](Vulkan/): the Vulkan render backend, windowing and window input.
- [Attributes](Attributes/): markers used by serializers, analyzers and generated code.

Optional features, including camera rigs and in-game UI, ship as [built-in bricks](../Packages/).
