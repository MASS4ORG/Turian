# Turian Editor

Authoring tools for Turian projects. Shared logic lives in [Core](Core/); desktop panels and commands live in the [Turian Gaya plugin](Gaya.Plugin/).

- [Studio](Studio/): the Gaya desktop workbench.
- [CLI](CLI/): compilation, builds, diagnostics and brick commands.
- [Bootstrap](Bootstrap/): desktop startup and service composition.
- [CSharp](CSharp/): serialization generators and code analyzers.

See the [build guide](../../docs/Building-from-source.md) for development setup.
