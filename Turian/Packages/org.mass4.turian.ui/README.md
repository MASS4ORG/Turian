# Turian UI

Built-in in-game UI based on Guinevere: UI documents, USS stylesheets, binding, images and screen or world panels.

Install `builtin:org.mass4.turian.ui` through the Bricks panel or the project manifest. Runtime and editor assemblies are built from `Source~/` into `Precast~/lib/` for distribution.
