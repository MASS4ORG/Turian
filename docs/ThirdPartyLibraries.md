# Third Party Libraries

Turian is built upon the following excellent open-source libraries:

| Library | License | Description |
| :--- | :--- | :--- |
| [Guinevere](https://github.com/MASS4ORG/Guinevere) | MIT | Cross-platform UI framework |
| [Silk.NET](https://github.com/dotnet/Silk.NET) | MIT | High-performance graphics (Vulkan/Compute) |
| [Serilog](https://github.com/serilog/serilog) | Apache 2.0 | Logging |
| [ZLogger](github.com/Cysharp/ZLogger) | MIT | Logging |

We extend our gratitude to the maintainers of these projects.
