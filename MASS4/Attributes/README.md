# MASS4 Attributes

Shared metadata for forms, editor tools, stable type identity and service discovery. Consumers implement the behavior; this library references neither Turian, Gaya nor a GUI toolkit.

Engine-specific component, asset and serialization rules remain in Turian.Engine.Attributes. The form implementation currently lives in Turian.Editor.Core; its extraction into Guinevere is tracked in Turian issue #194.
